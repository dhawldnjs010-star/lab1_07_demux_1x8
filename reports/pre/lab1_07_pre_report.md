## 1. 실험 목적과 확인할 것

입력 조합과 출력의 관계를 **진리표·파형으로 설명**한다. 이 실험의 입출력은 입력 `i`, `s[2:0]` / 출력 `o[7:0]`.

## 2. 예상 입력·출력 (진리표, 비트 순서: MSB가 왼쪽)

| i | s[2:0] | o[7:0] |
|---|---|---|
| 0 | 000 | 00000000 |
| 0 | 111 | 00000000 |
| 1 | 000 | 10000000 |
| 1 | 001 | 01000000 |
| 1 | 010 | 00100000 |
| 1 | 011 | 00010000 |
| 1 | 100 | 00001000 |
| 1 | 101 | 00000100 |
| 1 | 110 | 00000010 |
| 1 | 111 | 00000001 |

`i=0`이면 항상 0, `i=1`이면 `s=000 → o[7]` … `s=111 → o[0]`. 16개 조합 전부 TB가 검사한다.

## 3. 직접 작성한 코드와 파일 역할

작성 파일: `src/demux_1x8.v`, `sim/tb_demux_1x8.sv`, `constraints/pins.xdc`

```verilog
// src/demux_1x8.v
module demux_1x8(
    input  wire i,
    input  wire [2:0] s,
    output wire [7:0] o
);

    assign o = i ? (8'b10000000 >> s) : 8'b0;
endmodule
```

**설계 설명.** `o = i ? (8'b10000000 >> s) : 8'b0`. `i=0`이면 전부 0, `i=1`이면 최상위 비트를 s만큼 오른쪽으로 밀어 s번째 출력만 1이 된다.

| 파일 | 역할 |
|---|---|
| `src/*.v` | 설계(RTL). 합성 대상이며 TB를 넣지 않는다. |
| `sim/tb_demux_1x8.sv` | DUT 연결, 입력 자극, 예상값 검사(`$fatal`), `wave.vcd` 덤프(`$dumpfile`·`$dumpvars`), `$finish`. 입력을 10 ns 간격으로 바꾸며 16개 조합을 검사한다. |
| `constraints/pins.xdc` | 보드 핀 배정(PACKAGE_PIN·IOSTANDARD·get_ports). Icarus 기능 시뮬레이션의 입력이 아니다. |
| `simulation.json` | `sources`, `testbench`(`sim/tb_demux_1x8.sv`), `simulation_top`(`tb_demux_1x8`) 지정. |

## 7. 실험 당일 보드 확인 계획

- 장비: Spartan-7 XC7S75 교육용 보드(part `xc7s75fgga484-1`). 연결 전 전원·핀 기능·I/O 전압(LVCMOS33)을 확인하고, 배선 변경은 전원을 끈 상태에서 한다.
- 확인 계획: i=0에서 전 출력이 꺼지는지, i=1에서 s에 따라 정확히 한 LED만 켜지는지 확인한다.
- 조합회로라 클록이 없다. TB의 10 ns 간격은 검사를 빠르게 하기 위한 값이며, 보드에서는 스위치를 손으로 바꾸므로 **입력 조합**으로만 동작을 해석한다.
- 사진에는 보드 연결과 입력·출력 위치가 함께 보이게 촬영한다.
